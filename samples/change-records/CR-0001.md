# CR-0001: Alert on a WireGuard handshake from a never-seen address

Practice change record (synthetic data).

**What changes:** Adds the rule `rules/wireguard_new_address.yml`, its runbook `runbooks/wireguard_new_address.md`, its test `tests/wireguard_new_address.json` with the sample `tests/samples/wireguard_handshakes.jsonl`, and its row in `alert-catalog.md` (the row is already in the starter catalog). Branch: `cr-0001-new-address-rule`.

**Why:** A tunnel key used from an address it has never used before can mean the key was copied. Nothing alerts on this today.

**Risk:** Low. This adds a new alert and changes no existing one. It will also fire when a person connects from a new network (a false positive), which the runbook covers.

**Rollback:** Revert the merge commit of this change's pull request (`git revert -m 1 <merge-commit-id>`) through a new pull request.
